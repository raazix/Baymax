# LineGuard dashboard

User selected a familiar industrial dashboard. Use IBM Plex Sans, pale neutral working surfaces, graphite navigation, teal controls, and explicit red/amber status labels. Dense evidence remains readable. The rotor illustration is exact synthetic geometry. Real casting classification stays separate from synthetic rotor metrology.

## First surface
Operate mode: choose a replay, inspect the component and evidence, review risk/action, record an engineer decision, and inspect audit history. Empty, loading and backend failure states must be actionable. Mobile stacks panels without hiding evidence.

## Rounded workspace refinement
Shared radii: 16px working panels, 12px media and stage controls, 10px inputs/navigation, 8px compact status labels. Graphite sidebar is inset on the pale canvas. Keep border-defined surfaces, readable evidence tables, and teal actions; mobile controls stack with generous touch targets.
